# 25. 재정렬: 상위 20개를 다시 줄 세우기

> B6 · 검색 개선 · 수업 25 / 60 · [전체 목록](../../README.md#수업-목록)

## 이 수업에서 하는 것

- 바이 인코더로 넓게 찾고, 크로스 인코더로 좁게 다시 줄 세워요. 서류 심사 뒤 면접이에요.
- 점수가 큰 게 좋으면 마이너스를 붙여 정렬해요. 그리고 붙일 때마다 성적표로 재요.
- 이유를 다시 볼게요. 바이 인코더는 청크를 미리 숫자로 눌러 담아서 빠르지만 흐리고, 크로스 인코더는 질문과 함께 단어끼리 맞대어 봐서 정확하지만 쌍마다 새로 계산해요. 그래서 넓게 찾고 좁게 다시 줄 세우고, 1단계가 놓친 정답은 2단계가 살리지 못해요.

## 과제

1단계 후보를 스무 개에서 쉰 개로 늘려 보세요. 점수와 시간이 어떻게 바뀌는지 보세요.

## 풀이

<details><summary>풀이 보기</summary>

1단계의 20을 50으로 바꾸고, 시간 출력의 글자도 맞춰 바꿔요.
후보 쉰 개에서는 Recall@4 1.00, MRR 0.95, 시간은 질문당 4.37초예요.
39개 질문 모두 정답이 상위 4개 안에 들어왔어요. 대신 시간이 네 배 넘게 늘었어요. 한 문제를 더 맞히려고 질문마다 3초 넘게 더 쓸지는, 서비스의 시간 예산으로 정해요.

영상에서 입력한 그대로입니다.

- `b6/rerank.py`를 엽니다.
- 29행으로 갑니다.
- 그 자리의 줄 1개를 지웁니다.

```python
first = [np.argsort(-(vecs @ embed.encode(item["question"], normalize_embeddings=True)))[:50] for item in qa]  # 1단계: 벡터로 50개
```

- 38행으로 갑니다.
- 그 자리의 줄 1개를 지웁니다.

```python
print(f"재정렬 시간: 질문 하나당 {(time.time() - start) / len(qa):.2f}초 (청크 50개)")
```

- 실행: `uv run python b6/rerank.py`
