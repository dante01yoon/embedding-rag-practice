## 이 수업에서 하는 것

- LLM 심판에게는 자료를 함께 주고, 자료로 확인되는지를 물어요. 그냥 그럴듯한지를 물으면 바깥 지식을 못 잡아요.
- 심판은 정답을 아는 함정 문제로 시험해요. 그리고 함정이 진짜 함정인지부터 검사해요.
- 이유도 같이 기억해 두세요. 사람은 느리고, 낱말 겹침은 뜻을 못 봐서 LLM 심판을 써요. 하지만 심판에게도 버릇이 있으니, 잡은 비율과 오경보를 정답을 아는 문제로 재고 나서 믿어요.

## 과제

심판이 근거 없음이라고 한 그냥 답 하나를 직접 찍어서, 어느 부분이 자료에 없는지 눈으로 확인해 보세요.

## 풀이

<details><summary>풀이 보기</summary>

맨 끝에 한 줄을 넣어요. 심판이 근거 없음이라고 한 그냥 답 중 첫 번째를 앞 400자만 찍어요.
topologyKeys 질문의 그냥 답이에요. 앞부분은 자료 2번의 내용을 잘 옮겼어요. 그런데 아래에 예시라며 표를 붙였어요. 같은 노드, 같은 영역, 같은 리전에 백엔드가 없을 때를 칸마다 채운 표예요.
자료에는 이런 표가 없어요. 그럴듯하게 정리했지만, 칸 하나하나는 모델이 지어낸 거예요. 심판이 근거 없음이라고 한 이유를 우리 눈으로 확인했어요. 이렇게 판정 몇 개를 직접 열어 보는 게 심판을 믿는 방법이에요.
