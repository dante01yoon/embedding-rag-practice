# 02. LLM, 토큰, 그리고 왜 검색이 필요한가

> PART A · 기초 개념 · 수업 2 / 60 · [전체 목록](../../README.md#수업-목록)

## 이 수업에서 하는 것

- LLM은 마감일 뒤의 일과 내 문서를 몰라요. 답이 든 글을 붙여 주면 답할 수 있어요.
- 전부 붙일 수는 없으니 맞는 글을 골라야 하고, 그 양은 토큰으로 세요. 한국어는 토큰이 더 많이 나와요.
- 그리고 조각 사전은 모델마다 달라요. 같은 한국어 문장이 bge-m3에서는 영어의 1.2배, gpt2에서는 4.7배였어요.

## 과제

ask.py의 질문을 news.txt 속 다른 내용으로 바꿔서, 문서 없이와 문서 붙임의 답, 그리고 보낸 토큰 수를 비교해 보세요.

## 풀이

<details><summary>풀이 보기</summary>

질문을 문서 속 다른 내용, 논문이 언제 나왔고 기존 검색에 무엇을 더했는지로 바꾸고 두 번 실행해요.
문서 없이는 어떤 논문인지 확실하지 않다며 답하지 않았어요. 문서를 붙이니 2026년 7월, 여러 언어를 이해하는 임베딩 검색을 더했다고 정확히 답했어요. 보낸 토큰은 65에서 172로, 이번에도 문서 한 줄만큼 107토큰이 늘었어요.

영상에서 입력한 그대로입니다.

- `a1/ask.py`를 엽니다.
- 9행으로 갑니다.
- 그 자리의 줄 1개를 지웁니다.

```python
question = "Apple Music 검색 팀 논문은 몇 년 몇 월에 나왔고, 기존 검색에 무엇을 더했어? 한 문장으로."
```

- 실행: `uv run python a1/ask.py`
- 실행: `uv run python a1/ask.py --doc`

</details>
