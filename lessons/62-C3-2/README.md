# 62. 문서가 늘면 grep은 얼마나 느려지나

> C3 · 문서가 수십만 개일 때 — 끌어와서 grep · 수업 62 / 66 · [전체 목록](../../README.md#수업-목록)

## 이 수업에서 하는 것

- 색인이 없으면 문서가 늘어나는 만큼 열어 볼 파일도 늘어요. 낱말 하나를 찾는 데 1만 개에서 0.2초 안팎, 10만 개에서 2초대, 약 65만 개에서 15초쯤 걸렸어요.
- 찾는 시간은 폴더 크기를 따라가고, 결과 수는 낱말의 흔한 정도를 따라가요.
- 없는 것(none), 시간 초과(timeout), 명령 실패(bad_request)를 구분해서 도구의 첫 줄에 상태로 돌려줘요. 약 65만 개에서 통째로 뒤지기는 틀리지 않고 느려졌어요.

## 파일

| 파일 | 설명 |
|---|---|
| [`c3/bench.py`](../../c3/bench.py) | 수업 영상에서 빈 파일부터 입력하는 코드 · 묶음마다 찾기 한 번의 시간과 파일 수를 표로 |
| [`c3/find0.py`](../../c3/find0.py) | 수업 영상에서 빈 파일부터 입력하는 코드 · 첫 줄에 상태를 적어 돌려주는 find 첫 판 (다음 수업에서 `tools.py`로 키움) |

읽는 데이터: `wiki/10k/` (필수) · `wiki/100k/` (선택) — [C3 자료 받기](../../c3/README.md). 약 65만 개 전체 묶음(`wiki/all/`)은 강사 화면으로만 봅니다.

## 실행

먼저 문서 묶음을 받고 (이미 받았다면 건너뜁니다): [C3 자료 받기](../../c3/README.md)

`rg`(ripgrep)가 설치돼 있는지 확인합니다. 없으면 [자료 받기 안내의 사전 점검](../../c3/README.md#사전-점검-api-키-없이-됩니다)을 따라 설치합니다.

```bash
rg --version
```

수업 명령:

```bash
uv run python c3/bench.py 서울 훈민정음 텅스텐 "초대 시장" "1945년 12월"
uv run python c3/find0.py 서울 | head -5
uv run python c3/find0.py 없는낱말zzz
uv run python c3/find0.py "("
```

저장소 맨 위 폴더에서 실행합니다. 모델을 부르지 않으니 **OpenRouter 키가 필요 없고** 비용도 들지 않습니다.

- `bench.py`는 받지 않은 묶음을 건너뜁니다. 1만 개만 받았다면 표에 `1만` 칸만 나옵니다. 파일 수는 영상과 같고(서울 716개), 시간은 기기마다 다릅니다.
- `find0.py`는 차례로 `상태: truncated`(문서 716개 중 20개), `상태: none`, `상태: bad_request`가 나옵니다.

영상의 마지막 명령은 전체 묶음에서 제한 시간을 1초로 낮춰 `상태: timeout`을 보는 것입니다.

```bash
uv run python c3/find0.py 서울 wiki/all 1
```

전체 묶음은 받지 않으므로 이 명령을 그대로 치면 폴더가 없어서 `상태: bad_request`가 나옵니다. 받은 묶음으로 시간 초과를 보려면 제한 시간을 0초로 줍니다.

```bash
uv run python c3/find0.py 서울 wiki/10k 0
```

## 과제

낱말 다섯 개를 직접 골라 `bench.py` 표를 채워 보세요. 실습 자료를 전부 받지 않았다면 내려받은 묶음까지만 실행해도 괜찮아요. 표가 완성되면 가장 흔한 낱말과 가장 드문 낱말의 시간 차이를 확인해 보세요.

```bash
uv run python c3/bench.py 낱말1 낱말2 낱말3 낱말4 낱말5
```

## 풀이

<details><summary>풀이 보기</summary>

강사가 다섯 낱말로 채운 표에서 전체 묶음(약 65만 개) 칸을 보면 이래요.

| 낱말 | 파일 수 | 시간 |
|---|---|---|
| 서울 | 47,553개 | 14.98초 |
| 훈민정음 | 288개 | 15.36초 |
| 텅스텐 | 205개 | 15.19초 |
| 초대 시장 | 13개 | 15.88초 |
| 1945년 12월 | 490개 | 15.18초 |

가장 흔했던 서울은 47,553개 파일에 14.98초가 걸렸고, 가장 드물었던 초대 시장은 13개 파일만 나왔지만 15.88초가 걸렸어요. 결과가 13개뿐인 드문 낱말이라고 해서 더 빨리 끝나지 않았어요.

찾는 시간은 낱말의 빈도가 아니라 폴더의 크기가 정해요. 1만 개 묶음에서는 어느 낱말이든 0.17초에서 0.27초 사이였고, 10만 개 묶음에서는 2.14초에서 2.46초 사이였어요.

영상에서 입력한 그대로입니다.

- 실행: `uv run python c3/bench.py 서울 훈민정음 텅스텐 "초대 시장" "1945년 12월"`
