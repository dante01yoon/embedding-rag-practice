## 이 수업에서 하는 것

- 에이전트 검색은 LLM이 grep과 읽기를 반복해서 찾아요. 파일을 통째로 읽으면 입력이 2만 개를 넘었고, 40줄씩 읽게 하니 절반이 됐어요.
- 이 문서에서 정확도는 벡터 검색과 같고, 비용은 6배 넘게 비쌌어요. 대신 색인이 필요 없어요.
- 그리고 왜 비싼지도 기억해요. 모델은 지난 대화를 기억하지 못해서 차례마다 대화 전체를 다시 보내고, 읽은 내용이 길수록 그게 쌓여요.

## 과제

둘의 점수가 같다면, 맞힌 질문도 같을까요? 에이전트만 맞힌 질문과, 벡터 검색만 맞힌 질문을 세어 보세요.

## 풀이

<details><summary>풀이 보기</summary>

두 채점 결과를 질문별로 짝지어서, 한쪽만 맞힌 수를 세요.
에이전트만 맞힌 질문이 4개, 벡터 검색만 맞힌 질문도 4개예요. 점수는 같아도 잘하는 질문이 달라요.
그러니까 둘을 섞으면 더 많이 맞힐 수 있어요. 싼 벡터 검색으로 먼저 답하고, 모르겠다고 할 때만 에이전트를 부르는 거예요. 길 고르기 수업에서 직접 재 봐요.

영상에서 입력한 그대로입니다.

- `c2/agent.py`를 엽니다.
- 86행으로 갑니다.

```python
    print(f"에이전트만 맞힘 {sum(a and not r for a, r in zip(ag, rg))}개 · 벡터만 맞힘 {sum(r and not a for a, r in zip(ag, rg))}개")
```

- 실행: `uv run python c2/agent.py`
