# 35. GraphRAG: 관계를 따라 찾기

> B7~B9 · 답의 품질과 고급 RAG · 수업 35 / 60 · [전체 목록](../../README.md#수업-목록)

## 이 수업에서 하는 것

- GraphRAG는 노드와 엣지로 관계를 저장하고, 선을 따라 빠짐없이 찾아요. 작가의 책 모으기에서 벡터 0.55, 그래프 0.92였어요.
- 어려운 곳은 개체 연결이에요. 질문의 이름이 그래프의 점과 글자까지 맞지 않으면 아무것도 못 찾아요.
- 이유도 같이 기억해 두세요. 벡터는 뜻이 닮은 걸 찾고, 그래프는 관계를 따라 빠짐없이 모아요. 여러 걸음을 건너야 하는 질문은 그래프가 한 걸음씩 따라가면 되고, 대신 질문의 이름을 그래프의 점에 맞추는 개체 연결이 성패를 갈라요.

## 과제

놓친 다섯 명을 살려 보세요. 힌트는, 질문의 단어가 이미 그래프에 있으면 LLM에게 묻지 않고 그대로 쓰는 거예요.

## 풀이

<details><summary>풀이 보기</summary>

질문의 첫 단어를 꺼내서, 그 단어가 들어간 작가 점이 있으면 그대로 쓰고, 없을 때만 LLM에게 물어요.
그래프가 찾은 비율이 1.00, 찾은 것 중 맞는 비율도 0.92로 올랐어요. 고골, 게이먼, 칸트, 달, 그린이 다 살아났어요.
솔직하게 말하면, 오늘 질문은 그래프에 있는 이름으로 만들었으니 이 방법에 유리해요. 실제 사용자는 오타도 내고 별명도 써요. 그래서 현업에서는 이름마다 다른 표기들을 모아 둔 별칭 목록을 함께 만들어요.

영상에서 입력한 그대로입니다.

- `b9/graph.py`를 엽니다.
- 45행으로 갑니다.
- 그 자리의 줄 1개를 지웁니다.

```python
    word = q.split()[0]  # 질문의 첫 단어
    name = word if any(word in n for n in G if n.startswith("작가:")) else ask(f"다음 질문에 나오는 작가 이름만 출력하세요.\n\n{q}")  # 그래프에 있으면 그대로, 없을 때만 LLM
```

- 실행: `uv run python b9/graph.py`
