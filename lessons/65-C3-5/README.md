# 65. 세 방식 성적표 · 측정과 채점

> C3 · 문서가 수십만 개일 때 — 끌어와서 grep · 수업 65 / 66 · [전체 목록](../../README.md#수업-목록)

## 이 수업에서 하는 것

- 세 방식(검색만 · 통째로 뒤지기 · 끌어와서 뒤지기)을 같은 턴·토큰 한도에서 재고, 채점은 최종 답과 근거 확인으로 나눠요. 한도에 걸린 실행은 따로 세요.
- 약 65만 개 21문항에서 검색만 16·16·16, 통째로 뒤지기 20·21·20, 끌어와서 뒤지기 19·20·20이었고, 끌어와서 뒤지기는 질문당 15~20초로 통째로 뒤지기(79~95초)보다 훨씬 빨랐어요.
- 검색만은 발췌가 쌓여 입력 토큰과 비용을 가장 많이 썼어요. 글자 일치만 믿지 말고 LLM 심판과 근거 칸을 함께 봐요.

## 실행

먼저 문서 묶음을 받습니다 (이미 받았다면 건너뜁니다): [C3 자료 받기](../../c3/README.md)

수업 명령:

```bash
uv run python c3/report.py | head -18
uv run python c3/show.py A       # 래퍼 질문 · 검색만
uv run python c3/show.py pull    # 같은 질문 · 끌어와서 뒤지기
```

저장소 맨 위 폴더에서 실행합니다. 강사의 기록만 다시 보는 명령이라 **OpenRouter 키가 필요 없고** 비용도 들지 않습니다.

`measure.py`와 `judge.py`는 수업에서 코드를 입력하고 읽어 보는 파일입니다. 저장소에는 강사가 돌린 315회의 기록과 심판 판정이 들어 있어서, 성적표는 위의 `report.py`로 바로 볼 수 있습니다. 전체를 직접 다시 재려면 약 65만 개 전체 묶음까지 필요하고, 강사 기록으로 315회에 2.38달러가 들었습니다. 직접 돌려 보는 것은 아래 과제처럼 질문 하나씩 하면 됩니다.

## 과제

대표 문항 세 개만 골라 세 방식으로 각각 실행해 보세요. 실행이 끝나면 강사의 기록과 끝난 상태, 도구 호출 횟수를 비교해 보세요. 약 65만 개 전체가 부담스럽다면 1만 개 묶음으로 돌려도 괜찮아요. 다만 문서 수가 적으면 find 시간이 짧아져 실행 시간은 다르게 나와요.

대표 문항은 `q01`(쉬운 문항 · 기증 수목 수), `h02`(어려운 문항 · 래퍼와 초대 시장), `n01`(자료에 없음 · 2025학년도 신입생)이에요.

```bash
uv run python c3/agent.py q01 search 10k
uv run python c3/agent.py q01 raw 10k
uv run python c3/agent.py q01 pull 10k
```

`q01` 자리를 `h02`, `n01`로 바꿔 같은 세 줄을 실행합니다.

- **OpenRouter 키 필요.** 모델을 부릅니다. 아홉 번을 모두 돌리면 약 0.09달러입니다(강사의 1만 개 묶음 기록 기준. 문항과 방식에 따라 한 번에 0.001~0.04달러).
- `search`와 `pull` 방식은 색인이 있어야 합니다. 아직 만들지 않았다면 `uv run python c3/build_index.py 10k`를 먼저 실행합니다.
- 끝의 `10k`는 받은 묶음 이름입니다.

## 풀이

<details><summary>풀이 보기</summary>

강사가 약 65만 개 묶음에서 미리 돌린 세 문항의 기록이에요.

| 문항 | 검색만 | 통째로 뒤지기 | 끌어와서 뒤지기 |
|---|---|---|---|
| 쉬운 문항 · 기증 수목 수 | 정답 631그루 | 정답 631그루 · 41.7초 | 정답 631그루 · 4.8초 |
| 어려운 문항 · 래퍼와 초대 시장 | 도구 23번 뒤 토큰 한도에 걸림 | 정답 정종철 | 정답 정종철 |
| 자료에 없음 · 2025학년도 신입생 | 도구 20번 뒤 토큰 한도에 걸림 | 모름(맞음) · 도구 15번 | 모름(맞음) · 도구 18번 |

- 쉬운 문항은 세 방식 모두 맞혔지만, 걸린 시간은 끌어와서 뒤지기 4.8초, 통째로 뒤지기 41.7초로 갈렸어요.
- 어려운 문항에서 검색만은 도구를 23번이나 부르다 토큰 한도에 걸려 멈췄고, 나머지 두 방식은 정답 정종철을 찾았어요.
- 자료에 없는 문항에서 검색만은 이번에도 토큰 한도에서 멈췄어요. 나머지 두 방식은 자료에 없다는 걸 확인하고 모름으로 맞게 답했지만, 그러면서 도구를 각각 15번과 18번이나 썼어요. 없는 답을 확인하느라 도구를 많이 쓰는 이 문제는 다음 수업에서 다시 다뤄요.

래퍼 문항의 강사 기록은 키 없이 다시 볼 수 있어요.

```bash
uv run python c3/show.py A
uv run python c3/show.py raw
uv run python c3/show.py pull
```

1만 개 묶음에서 잰 강사 기록은 `uv run python c3/report.py`의 「10k · 1번째 실행」 표에 있어요.
