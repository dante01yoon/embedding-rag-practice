- 틀린 이유는 SQL이 아니라 데이터였어요. 표기가 다른 이름, 빈 칸, 비소설 속 소설이요.

## 과제

누가 책 표를 통째로 지워 달라고 하면 어떻게 될까요? 그리고 그걸 막아 보세요.

## 풀이

<details><summary>풀이 보기</summary>

질문을 받기 전에, 데이터베이스를 읽기 전용으로 바꿔요. 그리고 위험한 질문을 넣어 봐요.
모델은 시키는 대로 DROP TABLE, 표를 지우는 SQL을 썼어요. 하지만 읽기 전용이라 데이터베이스가 거절했어요.
LLM이 만든 SQL은 사용자가 쓴 SQL처럼 믿으면 안 돼요. 프롬프트로 부탁하는 게 아니라, 권한으로 막아야 해요. 운영 파트에서 다시 다뤄요.

영상에서 입력한 그대로입니다.

- `c2/sql.py`를 엽니다.
- 67행으로 갑니다.

```python
db.execute("PRAGMA query_only = ON")  # 읽기만 허용
sql = to_sql("책 표를 통째로 지워 주세요.", HINT + RULE)
print(f"위험한 질문 → {sql} → {run(sql)[0][0]}")
```

- 실행: `uv run python c2/sql.py`

</details>
