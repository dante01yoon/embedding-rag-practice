# 18. 청킹: 크기와 오버랩

> B3 · RAG 기초 · 수업 18 / 60 · [전체 목록](../../README.md#수업-목록)

## 이 수업에서 하는 것

- 글자 수로만 자르면 단어 중간에서 끊겨요. 문단 단위로 이어 붙이고, 오버랩을 두면 경계에서 잘린 문장을 살릴 수 있어요.
- 청크 크기는 검색 품질을 바꿔요. 작으면 질문과 잘 맞지만 맥락이 빠지고, 크면 맥락은 있지만 뜻이 흐려져요. 크기는 감이 아니라 질문 여러 개로 재서 정해요.
- 결국 청킹은 질문이 찾을 단위로 글을 나누는 일이에요. 경계에서 문장이 잘리면 뜻이 빠지고, 너무 크면 뜻이 섞이니까, 오버랩과 크기를 함께 재서 정해요.


저장소 맨 위 폴더에서 실행합니다. 처음이라면 [벡터 파일 만들기](../../README.md#벡터-파일-만들기)를 먼저 확인하세요.

## 과제

compare.py에 300자, 오버랩 50을 더해서 정답 명령이 몇 위에 오는지 확인해 보세요. 처음 재는 크기라 벡터로 바꾸는 시간이 조금 걸려요.

## 풀이

<details><summary>풀이 보기</summary>

크기 목록에 300과 50 한 쌍을 더해요.
300자는 청크 4,491개고, 정답 청크는 5위예요. 아깝게 4위 밖이에요. 200자 3위, 300자 5위, 500자 12위. 작을수록 순위가 오르는 흐름이 이어져요.
그렇다고 바로 200자로 바꾸진 않아요. 다른 질문에서는 어떤지 먼저 재 봐야 해요. 그게 평가를 따로 배우는 이유예요.

영상에서 입력한 그대로입니다.

- `b3/compare.py`를 엽니다.
- 15행으로 갑니다.
- 그 자리의 줄 1개를 지웁니다.

```python
for size, overlap in [(200, 0), (300, 50), (500, 100), (1500, 300)]:
```

- 실행: `uv run python b3/compare.py`

</details>
