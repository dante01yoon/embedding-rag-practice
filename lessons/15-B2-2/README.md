# 15. 사전 필터 vs 사후 필터

> B2 · 벡터 저장소 · 수업 15 / 60 · [전체 목록](../../README.md#수업-목록)

## 이 수업에서 하는 것

- 사후 필터는 찾고 나서 거르니 결과 수를 보장하지 못하고, 사전 필터는 조건 안에서 찾아서 결과 수가 안정적이에요.
- 사전 필터를 쓰려면 메타데이터가 꼭 붙어 있어야 하고, 없으면 오류 없이 빈 결과가 나와요. 그리고 사전 필터는 먼 책도 채워 넣으니, 개수와 거리를 같이 봐야 해요.
- 그럼 언제 무엇을 쓸까요? 조건이 넓고 흔하면 넉넉히 찾는 사후 필터로도 충분하고, 조건이 좁고 드물면 사전 필터가 필요해요. 어느 쪽이든 먼저 메타데이터가 붙어 있는지부터 확인해요.

## 과제

사후 필터에서 처음에 찾는 수를 6에서 50으로 늘리고, 남은 것 중 여섯 권만 보여 주세요. 지난 섹션 앱처럼요. 한 권도 안 나오던 마법 학교가 어떻게 되는지 확인해 보세요.

## 풀이

<details><summary>풀이 보기</summary>

사후 필터 쪽의 n_results를 50으로 바꾸고, 남긴 목록 끝에 대괄호 콜론 6을 붙여 여섯 권만 남겨요.
이제 두 질문 모두 사후 필터도 여섯 권이에요. 그리고 사전 필터와 똑같은 책, 똑같은 순서예요. 넉넉히 찾으면 사후 필터도 충분히 쓸 만해요.
다만 천만 개 데이터에서 조건에 맞는 게 아주 드물면, 50개로도 모자랄 수 있어요. 그래서 데이터 규모와 조건이 얼마나 드문지 보고 고르세요.

영상에서 입력한 그대로입니다.

- `b2/filter.py`를 엽니다.
- 24행으로 갑니다.
- 그 자리의 줄 1개를 지웁니다.

```python
    res = col.query(query_embeddings=[q], n_results=50)  # 나중에 거르기: 6권 찾고 → 비소설만 남긴다
```

- 25행으로 갑니다.
- 그 자리의 줄 1개를 지웁니다.

```python
    after = [t for t, m in zip(titles(res), res["metadatas"][0]) if m["kind"] == "비소설"][:6]
```

- 실행: `uv run python b2/filter.py`
