# 11. 제로샷 분류: 소설과 비소설

> B1 · 도서 추천 앱 · 수업 11 / 60 · [전체 목록](../../README.md#수업-목록)

## 이 수업에서 하는 것

- 제로샷 분류는 책 소개를 전제로, 칸 이름을 넣은 문장을 가설로 두고 NLI 모델의 함의 점수가 높은 칸을 고르는 방법이에요.
- 정답은 장르 칸에서 만들었고, 논픽션 안의 픽션 같은 함정은 직접 열어 봐서 잡았어요. 정확도는 베이스라인과 칸별 점수를 같이 봐야 해요.

## 과제

기본 가설은 영어 문장이었죠. 가설을 한국어로, 이 글은 무엇에 대한 소개이다로 바꿔서 정확도와 칸별 점수가 어떻게 바뀌는지 확인해 보세요.

## 풀이

<details><summary>풀이 보기</summary>

가설 문장을 HYP에 적고, 분류기를 부를 때 hypothesis_template으로 넘겨요. 중괄호 자리에 칸 이름이 들어가요.
결과가 흥미로워요. 전체 정확도는 0.886에서 0.853으로 내려갔어요. 그런데 비소설은 0.63에서 0.79로 크게 올랐고, 소설은 0.94에서 0.87로 내려갔어요.
무엇이 더 좋은지는 쓰임에 달려 있어요. 비소설 필터를 자주 쓰는 앱이라면 한국어 가설이 나을 수 있어요. 이번 강의에서는 기본 가설을 그대로 써요.

영상에서 입력한 그대로입니다.

- `b1/classify.py`를 엽니다.
- 17행으로 갑니다.
- 그 자리의 줄 1개를 지웁니다.

```python
HYP = "이 글은 {}에 대한 소개이다."  # 가설 문장을 한국어로
books["pred"] = [clf(d, ["소설", "비소설"], hypothesis_template=HYP)["labels"][0] for d in books["description"]]
```

- 실행: `uv run python b1/classify.py`
