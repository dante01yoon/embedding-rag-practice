# 21. Streamlit 채팅 화면

> B4 · 프레임워크와 화면 · 수업 21 / 60 · [전체 목록](../../README.md#수업-목록)

## 이 수업에서 하는 것

- Streamlit은 입력마다 코드를 처음부터 다시 돌려요. 그래서 대화 기록은 세션 상태에, 처음 한 번만 만들어요.
- 질문마다 검색은 한 번, 답은 흘려 보여 주고, 출처는 펼쳐 보게 해요. 이번 섹션에서 40줄 RAG를 LangChain 부품으로 바꾸고 채팅 화면까지 만들었어요.
- 왜 이렇게 만들까요? 다시 실행 구조 덕분에 화면 코드는 위에서 아래로 읽기만 하면 되고, 남길 것만 메모장에 적으면 돼요. 다만 메모장은 화면용이라, 앞 대화를 이해하는 챗봇은 질문을 고쳐 쓰는 단계가 따로 필요해요.

## 파일

| 파일 | 설명 |
|---|---|
| [`b4/chat.py`](../../b4/chat.py) | 수업 영상에서 빈 파일부터 입력하는 코드 |

## 실행

```bash
uv run streamlit run b4/chat.py
```

저장소 맨 위 폴더에서 실행합니다. 처음이라면 [벡터 파일 만들기](../../README.md#벡터-파일-만들기)를 먼저 확인하세요.

## 과제

사이드바에 대화 지우기 버튼을 붙여 보세요. 누르면 대화 기록이 비워지게요. 오늘 배운 세션 상태를 쓰면 돼요.

## 풀이

<details><summary>풀이 보기</summary>

기록을 만드는 줄 바로 아래에, st.sidebar.button으로 대화 지우기 버튼을 만들고, 눌렸으면 세션 상태의 기록을 빈 목록으로 바꿔요.
질문을 하나 하고, 왼쪽 사이드바의 대화 지우기를 눌러요. 대화가 비워졌어요. 버튼을 눌러도 코드가 처음부터 다시 돌고, 이번엔 우리가 원해서 비운 거예요.

영상에서 입력한 그대로입니다.

- `b4/chat.py`를 엽니다.
- 9행으로 갑니다.

```python
if st.sidebar.button("대화 지우기"):
    st.session_state.messages = []
```
