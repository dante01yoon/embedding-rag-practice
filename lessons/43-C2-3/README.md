## 이 수업에서 하는 것

- 방법마다 잘하는 질문과 비용이 달라서, 한 표로 놓고 고르면 돼요.
- 라우터는 싼 길이 정직하게 모른다고 말해야 작동해요. 평범한 프롬프트로는 0개를 넘겼고, 엄격한 프롬프트로는 6개만 넘겨서 가장 많이 맞혔어요.
- 그리고 이유도 기억해요. 비용은 넘기는 비율이 정하고, 신호는 코드가 읽을 수 있게 정해 둬야 하고, 자신 있게 틀린 답은 라우터가 못 잡아요.

## 과제

에이전트로 넘긴 질문 여섯 개 중에서, 에이전트는 몇 개를 맞혔을까요?

## 풀이

<details><summary>풀이 보기</summary>

넘긴 질문만 골라서 채점해요.
여섯 개 중 네 개를 맞혔어요. 검색이 모른다고 한 질문 여섯 개 가운데 네 개를 에이전트가 살렸어요.
나머지 두 개는 에이전트도 못 찾았어요. 실무에서는 이런 질문을 사람에게 넘기거나, 문서에 빠진 내용을 채워요. 다음 파트에서는 이 시스템을 실제로 운영하는 법을 다뤄요.

영상에서 입력한 그대로입니다.

- `c2/route.py`를 엽니다.
- 40행으로 갑니다.

```python
moved = [r for r in res if r[3]]  # 에이전트로 넘긴 질문
print(f"넘긴 {len(moved)}개 중 에이전트가 맞힘 {sum(right(x, a) for x, a, _, _ in moved)}개")
```

- 실행: `uv run python c2/route.py`
