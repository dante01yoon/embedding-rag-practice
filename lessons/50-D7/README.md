## 이 수업에서 하는 것

- 모델을 바꿀 땐 문서와 질문을 모두 같은 새 모델로 바꿔야 해요. 색인마다 모델 버전을 기록하고, 질문도 그 기록대로 바꿔요.
- 새 색인을 따로 만들어 같은 골든셋으로 비교하고, 별칭 하나만 바꿔 전환하고, 필요하면 되돌려요.
- 이렇게 하는 이유는 하나예요. 모델마다 지도가 달라서 섞이면 에러 없이 틀리고, 서비스는 바꾸는 동안에도 멈추면 안 되니까요. 그래서 기록하고, 옆에 만들고, 재고, 한 번에 바꿔요.

## 과제

88.5퍼센트와 87.2퍼센트, 차이는 1.3퍼센트포인트예요. 이 차이가 진짜 차이일까요? 최종 미션의 부트스트랩으로 두 모델 차이의 신뢰구간을 구해 보세요.

## 풀이

<details><summary>풀이 보기</summary>

두 모델의 질문별 맞힘 목록을 같은 뽑기로 2,000번 다시 뽑아서, 그때마다 두 평균의 차이를 재요. 같은 질문을 뽑아야 공정하게 비교돼요.
차이는 1.3퍼센트포인트, 95퍼센트 신뢰구간은 마이너스 3.8에서 7.7퍼센트포인트예요. 0을 포함하니, 이 골든셋으로는 두 모델이 다르다고 말할 수 없어요. 서로 다르게 맞힌 질문은 5개뿐이에요.
그렇다면 벡터가 세 배 작고 색인도 빠른 e5-small로 바꾸는 것도 검토할 만해요. 다만 골든셋을 더 늘려서 다시 재 보고 결정하는 게 안전해요.

영상에서 입력한 그대로입니다.

- `d7/swap.py`를 엽니다.
- 61행으로 갑니다.

```python

a, b = hits("v1-bge-m3"), hits("v2-e5-small")  # 같은 질문 78개에서 맞힘/틀림
idx = np.random.default_rng(0).choice(len(qa), (2000, len(qa)))  # 질문을 복원 추출로 2,000번 다시 뽑기 (두 모델에 같은 뽑기)
diff = (a[idx].mean(1) - b[idx].mean(1)) * 100
print(f"차이 {(a.mean() - b.mean()) * 100:.1f}%p · 95% 신뢰구간 {np.percentile(diff, 2.5):.1f} ~ {np.percentile(diff, 97.5):.1f}%p · 서로 다르게 맞힌 질문 {int((a != b).sum())}개")
```

- 실행: `uv run python d7/swap.py`
