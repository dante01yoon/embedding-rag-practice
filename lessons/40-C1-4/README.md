# 40. 근거 없는 답 · 환각 재고 줄이기

> PART C · 벡터의 한계와 다른 길 · 수업 40 / 60 · [전체 목록](../../README.md#수업-목록)

## 이 수업에서 하는 것

- RAG를 붙여도 그냥 프롬프트는 넷 중 한 문장 꼴로 자료에 없는 말을 했어요. 엄격한 프롬프트는 0이었어요.
- 근거성은 답을 문장으로 나눠 자료와 대조해 재요. 그리고 심판의 규칙도 검사 대상이에요. 거절을 환각으로 세면 숫자가 틀려요.
- 왜 생기는지도 기억해 두세요. 자료를 줘도 머릿속 기억은 그대로라, 빈칸이 생기면 모델은 찍어서 채워요. 그래서 탈출구를 주고, 문장마다 재고, 여러 겹으로 걸러요.

## 과제

엄격하게 만든 대가는 없을까요? 답이 있는 질문 39개 중 몇 개를 거절했는지 세어 보세요.

## 풀이

<details><summary>풀이 보기</summary>

질문마다 답 문장 중에 정해진 거절 문장이 있는지 세요.
그냥은 하나도 거절하지 않았고, 엄격은 39개 중 7개를 거절했어요. 근거 없는 말은 사라졌지만, 대신 답할 수 있었던 질문 일곱 개를 놓쳤어요.
확인해 보니 그 일곱 개는 모두, 정답이 든 청크를 검색이 가져오지 못한 경우였어요. 그래서 거절이 늘면 프롬프트가 아니라 검색을 고쳐야 해요. 하이브리드 검색과 재순위가 여기서 다시 쓰여요.

영상에서 입력한 그대로입니다.

- `c1/ground.py`를 엽니다.
- 55행으로 갑니다.

```python
    refused = sum(any(s == "자료에 없습니다." for _, s in sentences(tmpl, q)) for q in QS[:-len(NO)])
    print(f"   답이 있는 질문 {len(QS) - len(NO)}개 중 거절 {refused}개")
```

- 실행: `uv run python c1/ground.py`
