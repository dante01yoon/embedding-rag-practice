## 과제

그림 경로의 22개 중에서, 정말 맞는 쪽을 보고 맞힌 건 몇 개인지 세어 보세요.

## 풀이

<details><summary>풀이 보기</summary>

그림 답이 맞고, 보여 준 쪽이 정답 쪽과 같은 것만 세는 두 줄을 넣어요.
맞는 쪽을 보고 맞힌 건 14개예요. 나머지는 엉뚱한 쪽을 보고도 외운 걸로 맞힌 거예요.
그림 경로는 검색이 쪽을 제대로 찾아 줘야 의미가 있어요. 정답만 볼 게 아니라, 어떤 근거를 보고 맞혔는지도 함께 확인해요.

영상에서 입력한 그대로입니다.

- `b9/table.py`를 엽니다.
- 91행으로 갑니다.

```python
real = sum(hit(gold, a) and p == pn for q, gold, pn in Q for a, p in [by_image(q)])  # 맞는 쪽을 보고 맞힌 것만
print("그림: 맞는 쪽을 보고 맞힌 수", real)
```

- 실행: `uv run python b9/table.py`
