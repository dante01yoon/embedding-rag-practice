# 19. 40줄로 RAG 만들기

> B3 · RAG 기초 · 수업 19 / 60 · [전체 목록](../../README.md#수업-목록)

## 이 수업에서 하는 것

- RAG는 검색한 청크에 번호를 붙여 프롬프트에 넣고, LLM에게 그 번호로 근거를 달게 하는 거예요. 오픈북 시험에서 쪽 번호를 적게 하는 것처럼요.
- API 키는 별도 파일에 두고 load_dotenv로 불러와요. 이 40줄이 이 강의 모든 RAG의 뼈대예요.
- 이유도 같이 기억해 두세요. 질문도 색인과 같은 모델로 바꿔야 같은 지도에서 찾을 수 있고, k는 놓치는 비율과 프롬프트 길이 사이의 저울질이에요. 그리고 출처 번호가 있어야 틀린 답이 검색 탓인지 생성 탓인지 나눌 수 있어요.

## 과제

프롬프트에서 자료에 없으면 모른다고 답하라는 문장을 지우고, 응시료 질문을 다시 해 보세요. 답이 어떻게 달라지는지 보세요.

## 풀이

<details><summary>풀이 보기</summary>

지시 줄에서 마지막 문장, 자료에 없으면 모른다고 답하세요를 지워요.
결과가 의외예요. 지시를 지웠는데도 자료에 정보가 없다고 했어요. 요즘 모델은 아래 자료만 보고 답하라는 첫 지시만으로도 꽤 잘 참아요.
그런데 준비하면서 질문 끝에 자료에 없으면 일반 지식으로 답해도 돼요를 붙여 봤더니, 자료에 없는 응시료 숫자를 자신 있게 말했어요. 그 숫자는 우리 문서 어디에도 없어서, 맞는지 확인할 방법이 없어요.
그래서 지시는 남겨 둬요. 모델이 바뀌어도, 사용자가 무엇을 덧붙여도 자료 밖으로 나가지 않게 하는 안전띠예요.

영상에서 입력한 그대로입니다.

- `b3/rag.py`를 엽니다.
- 26행으로 갑니다.
- 그 자리의 줄 1개를 지웁니다.

```python
    prompt = (f"아래 자료만 보고 답하세요. 문장 끝에 근거 번호를 [1]처럼 붙이세요.\n\n"
```

- 실행: `uv run python b3/rag.py "쿠버네티스 공인 자격증 시험 응시료는 얼마인가요?"`

</details>
