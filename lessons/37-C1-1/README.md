# 37. 벡터가 원리상 못 찾는 질문 · LIMIT 축소판

> PART C · 벡터의 한계와 다른 길 · 수업 37 / 60 · [전체 목록](../../README.md#수업-목록)

## 이 수업에서 하는 것

- 단일 벡터는 문서를 상자 하나에 담아서, 조합이 아주 다양한 질문에는 원리상 한계가 있어요. 우리 판에서 벡터 0.01, BM25 1.00이었어요.
- 그리고 BM25도 질문을 제대로 잘라 넣어야 이겨요. 띄어쓰기로만 자르면 조사 때문에 0.00이었어요.
- 왜인지도 기억해 두세요. 벡터 검색은 질문 방향 하나로 맨 앞의 둘을 고르는 구조라, 만들 수 있는 조합이 차원과 배치에 묶여요. 숫자를 마음대로 고르면 8차원이면 됐지만, 뜻으로 만든 1024차원 벡터는 0.01이었어요.

## 파일

| 파일 | 설명 |

```bash
uv run python c1/limit.py
```

저장소 맨 위 폴더에서 실행합니다. 처음이라면 [벡터 파일 만들기](../../README.md#벡터-파일-만들기)를 먼저 확인하세요.

## 과제

좋아하는 것을 남색 고양이처럼 띄어 써서 다시 재 보세요. 키워드 검색은 여전히 이길까요?

## 풀이

<details><summary>풀이 보기</summary>

things를 만드는 줄에서 색과 물건 사이에 띄어쓰기를 넣어요.
이번엔 벡터 0.01, BM25 0.02이에요. BM25도 크게 떨어졌어요.
남색과 고양이가 따로 놀면, 남색 무언가와 무언가 고양이를 좋아하는 다른 사람도 점수를 받아요. BM25가 이긴 건 키워드라서가 아니라, 정확히 같은 글자 덩어리 하나가 있었기 때문이에요. 그래서 제품 번호나 오류 코드처럼 쪼개지지 않는 꼬리표는 따로 정확히 일치하는 필드로 두기도 해요.

영상에서 입력한 그대로입니다.

- `c1/limit.py`를 엽니다.
- 17행으로 갑니다.
- 그 자리의 줄 1개를 지웁니다.

```python
things = [c + " " + i for c in COLORS for i in ITEMS]  # "파란 고양이"처럼 띄어 써서 1,050가지
```

- 실행: `uv run python c1/limit.py`
