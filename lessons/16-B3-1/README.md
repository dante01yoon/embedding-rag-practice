# 16. RAG 한눈에 보기

> B3 · RAG 기초 · 수업 16 / 60 · [전체 목록](../../README.md#수업-목록)

## 이 수업에서 하는 것

- RAG는 색인, 검색, 생성 세 단계예요. 색인은 미리 한 번, 검색과 생성은 질문이 올 때 해요.
- 출처 번호가 있어야 답을 확인할 수 있고, 검색이 놓치면 답도 없어요. 틀렸을 땐 LLM보다 먼저, 검색된 청크를 들여다보세요.
- 왜 이렇게 나눌까요? 문서를 카드처럼 잘라 두면 질문에 맞는 부분만 골라 붙일 수 있고, 벡터는 미리 한 번만 만들어 두면 질문마다 빠르게 찾을 수 있어서예요.

## 과제

질문을 바꿔서 정답 청크의 순위가 어떻게 달라지는지 보세요. 예를 들어 질문에 명령 이름 kubectl rollout undo를 직접 넣어 보세요.

## 풀이

<details><summary>풀이 보기</summary>

아홉째 줄 질문을 kubectl rollout undo는 무엇을 하나요로 바꾸고 다시 실행해요.
정답 청크가 1위로 올라왔어요. 상위 네 개에 롤백 이야기가 가득해요. 질문에 문서와 같은 단어가 있으면 훨씬 잘 찾아요.
하지만 사용자는 보통 명령 이름을 몰라서 물어봐요. 그래서 뜻으로 찾는 검색과 단어로 찾는 검색을 섞는 방법을 뒤 섹션에서 배워요.

영상에서 입력한 그대로입니다.

- `b3/peek.py`를 엽니다.
- 9행으로 갑니다.
- 그 자리의 줄 1개를 지웁니다.

```python
q = model.encode("kubectl rollout undo는 무엇을 하나요?", normalize_embeddings=True)
```

- 실행: `uv run python b3/peek.py`

</details>
