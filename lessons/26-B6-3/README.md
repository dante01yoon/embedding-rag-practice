# 26. 질의 변환: 여러 질문 · 가상의 답

> B6 · 검색 개선 · 수업 26 / 60 · [전체 목록](../../README.md#수업-목록)

## 이 수업에서 하는 것

- 멀티 쿼리는 질문을 여러 말로 늘려 RRF로 합치고, HyDE는 가상의 답으로 검색해요. 둘 다 질문마다 LLM을 불러요.
- LLM이 들어가면 점수가 흔들려요. 캐시로 고정하고, 여러 번 재고, 질문 세트에 맞는지 보고 붙여요.
- 이유를 다시 볼게요. 질문과 문서는 글 모양이 달라서 거리가 생겨요. 멀티 쿼리는 여러 자리에서 찾아 투표로 빗나감을 줄이고, HyDE는 문서 모양의 글로 바꿔 거리를 줄여요. 대신 LLM이 들어가서 느려지고, 흔들리고, 틀릴 수 있어요.

## 과제

질문을 사람들이 검색창에 치듯 두세 단어로 줄여서, 같은 성적표를 다시 매겨 보세요. 줄이는 것도 LLM에게 시켜요.

## 풀이

<details><summary>풀이 보기</summary>

성적표 위에 한 줄을 넣어요. 질문마다 LLM에게 두세 단어로 줄여 달라고 해서 질문을 바꿔요. 줄인 질문 세 개도 찍어 봐요.
줄인 질문은 emptyDir 저장소 위치처럼 나왔어요. 그대로는 0.87과 0.78, 여러 질문은 0.82와 0.80, 가상의 답은 0.87과 0.79예요.
줄이기만 했는데 그대로의 Recall이 0.95에서 0.87로 떨어졌어요. 이번엔 가상의 답이 그대로를 따라잡았어요. 질문이 짧을수록 고칠 여지가 생기는 거예요. 다만 오늘 본 흔들림이 0.08이라, 이 정도 차이로 이겼다고 하긴 일러요. 질문을 늘려서 다시 재 봐요.

영상에서 입력한 그대로입니다.

- `b6/query.py`를 엽니다.
- 53행으로 갑니다.

```python
qa = [{**x, "question": ask(f"다음 질문을 사람들이 검색창에 대충 치듯 2~4 단어로 줄여 주세요. 줄인 말만 출력.\n\n{x['question']}")} for x in qa]
print([x["question"] for x in qa[:3]])  # 줄인 질문 맛보기

```

- 실행: `uv run python b6/query.py`

</details>
