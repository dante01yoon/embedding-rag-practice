# 12. 분위기 점수 붙이기

> B1 · 도서 추천 앱 · 수업 12 / 60 · [전체 목록](../../README.md#수업-목록)

## 이 수업에서 하는 것

- 분위기 점수는 책 소개와 분위기 기준 문장의 코사인 유사도예요. 검색과 같은 원리고, 행렬 곱 한 번으로 모든 책을 재요.
- 기준 문장마다 평균이 달라서 평균을 뺐고, 같은 단어에 끌리는 한계는 직접 읽어서 확인해요.
- 이유도 기억해요. 책 벡터는 한 번만 만들고 분위기 문장만 바꾸면 되니 빠르고, 기준 문장은 구체적으로 써야 뜻이 좁혀져요. 점수는 좁은 띠에 몰려 있어서 평균을 빼야 공평하게 비교돼요.

## 과제

무서운이라는 분위기를 하나 더 만들어 보세요. 기준 문장을 직접 써서 넣고, 상위 세 권이 그럴듯한지 읽어 보세요.
