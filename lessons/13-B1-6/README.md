## 이 수업에서 하는 것

- 이번 프로젝트에서 데이터 살펴보기, 정제, 벡터 DB, 분류, 분위기 점수, 화면까지 여섯 단계를 직접 만들었어요.
- 오늘은 검색 함수를 먼저 터미널로 확인하고, Gradio로 화면을 붙였어요. 사후 필터는 넉넉히 찾아야 하고, 앞 단계의 실수는 화면까지 넘어온다는 것도 확인했어요.
- 이유도 같이 기억해요. 화면은 값을 넘기고 결과를 그리는 창구라서, 검색 함수를 따로 시험할 수 있어요. 무거운 모델은 앱을 켤 때 한 번만 열고, 거를 거라면 넉넉히 찾아요.

## 과제

저자 칸 앞에 대괄호 두 개가 붙은 저자가 56명이에요. 정제 수업에서 배운 방법으로 지워 보고, 비밀의 화원 저자가 깨끗하게 나오는지 확인해 보세요.

## 풀이

<details><summary>풀이 보기</summary>

책 표를 읽은 바로 아래에, 저자 칸 왼쪽의 대괄호를 떼는 줄을 넣어요. lstrip은 왼쪽 끝에서 지정한 글자를 떼어 내요. 그리고 시험 줄을 실제 일기 질문으로 바꿔 저자도 찍어요.
비밀의 화원 저자가 프랜시스 호지슨 버넷으로 깨끗하게 나왔어요. 이렇게 화면에서 찾은 문제는 원인이 된 단계로 돌아가 고쳐요. 제대로 하려면 정제 코드에 넣는 게 맞아요.

영상에서 입력한 그대로입니다.

- `b1/app.py`를 엽니다.
- 7행으로 갑니다.

```python
books["author"] = books["author"].str.lstrip("[")  # 위키 링크 조각 [[ 떼기
```

- 22행으로 갑니다.
- 그 자리의 줄 1개를 지웁니다.

```python
print(search("병과 싸운 소녀가 쓴 실제 일기", "비소설", "상관없음")[["title", "author", "kind"]])
```

- 실행: `uv run python b1/app.py`

</details>
