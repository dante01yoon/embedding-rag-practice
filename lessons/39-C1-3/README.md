# 39. "전부 몇 개?" 집계 질문

> PART C · 벡터의 한계와 다른 길 · 수업 39 / 60 · [전체 목록](../../README.md#수업-목록)

## 이 수업에서 하는 것

- 검색은 상위 k개만 꺼내서, 정답이 k보다 많은 집계 질문은 원리상 틀려요. 4개면 0명, 20개면 8명이었어요.
- LLM에게는 조건만 뽑게 하고, 세는 일은 표와 코드로 하면 14명 모두 맞혀요. 질문의 종류에 맞는 길로 보내요.
- 왜 틀리는지도 기억해 두세요. 검색은 줄 세워 앞에서 자르는 도구라 전체 개수를 몰라요. 그리고 틀린 답은 거의 다, LLM이 아니라 검색이 책을 덜 꺼내 온 탓이었어요.

## 과제

k를 50까지 늘리면 몇 명을 맞힐까요? 직접 재 보세요.

## 풀이

<details><summary>풀이 보기</summary>

k 목록에 50을 더해요.
50권을 보여 주면 14명 중 11명이에요. 여전히 세 명은 틀렸어요. 그리고 질문마다 책 50권을 읽히는 비용이 들어요.
표에서 세기는 14명 모두, 거의 공짜예요. 더 많이 보여 주기가 답이 아니라, 맞는 도구로 보내기가 답이에요.
LLM을 빼고 검색만 따로 재 보면, 50권일 때는 165권 중 162권이 들어오고 책이 전부 들어온 작가가 12명이에요. LLM은 그중 11명을 맞혔어요. 이번에도 하루키를 일곱 권으로 센 한 번이 빠졌어요.
k를 키우는 건 천장을 조금씩 올리는 일일 뿐이에요. 그 천장마저 질문마다 50권어치 토큰을 내고 사는 거고요.

영상에서 입력한 그대로입니다.

- `c1/count.py`를 엽니다.
- 38행으로 갑니다.
- 그 자리의 줄 1개를 지웁니다.

```python
for k in (4, 20, 50):
```

- 실행: `uv run python c1/count.py`
