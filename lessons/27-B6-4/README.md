# 27. 라우팅과 셀프 쿼리

> B6 · 검색 개선 · 수업 27 / 60 · [전체 목록](../../README.md#수업-목록)

## 이 수업에서 하는 것

- 라우팅은 질문을 보고 어디서 찾을지 골라요. 셀프 쿼리는 질문에서 조건을 뽑아 필터로 먼저 거르고, 그 안에서 벡터로 찾아요.
- LLM의 JSON은 울타리가 붙어 올 수 있으니 중괄호 부분만 꺼내요. 그리고 날짜처럼 LLM이 모르는 건 직접 알려 줘요.
- 이유를 다시 볼게요. 벡터는 뜻이 닮은 정도라서 2009년과 2010년을 가르지 못해요. 그래서 조건은 LLM이 뽑아 필터로 먼저 거르고, 뜻은 벡터로 찾아요. 나중에 거르면 후보가 모자랄 수 있고, 라우팅도 단어보다 뜻으로 골라야 해요.

## 과제

최근 10년이 제대로 계산되도록, LLM에게 오늘 날짜를 알려 주세요. 조건이 어떻게 바뀌는지 보세요.

## 풀이

<details><summary>풀이 보기</summary>

datetime에서 date를 가져오고, 프롬프트 맨 앞에 오늘은 몇 년 몇 월 며칠입니다를 붙여요.
최근 10년이 2016년부터 2026년으로 바뀌었어요. 오늘 날짜를 알려 주니 제대로 계산했어요. 다른 조건도 그대로 잘 뽑혔고, 셀프 쿼리는 이번에도 마흔 권 모두 조건을 지켰어요.
프롬프트가 바뀌면 캐시에 없는 새 질문이라 LLM을 다시 불러요. 그래서 일부 조건이 조금 달라질 수 있어요. 1950년 이전이 1949까지로 바뀐 것처럼요. 어느 쪽이 맞는지는 우리가 정해서 프롬프트에 적어 둬요.

영상에서 입력한 그대로입니다.

- `b6/route.py`를 엽니다.
- 4행으로 갑니다.

```python
from datetime import date
```

- 42행으로 갑니다.
- 그 자리의 줄 1개를 지웁니다.

```python
    raw = ask(f"오늘은 {date.today()}입니다. " + SELF + q)
```

- 실행: `uv run python b6/route.py`
