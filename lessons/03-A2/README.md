## 이 수업에서 하는 것

- 내적은 같은 자리끼리 곱해서 더한 값, 코사인은 방향만 비교한 값, 거리는 끝 사이의 길이예요.
- 길이를 1로 맞추면 내적이 코사인과 같아져요. 임베딩 검색은 보통 이렇게 정규화해서 써요.
- 실제 크기에서는 넘파이가 반복문보다 약 192배 빨랐고, 길이를 1로 맞춘 벡터는 내적과 거리가 같은 순위를 줬어요.

## 과제

화살표 e를 0, 5로 하나 더 만들어서, a와 e의 코사인과 거리를 손으로 먼저 계산하고, 코드로 맞는지 확인해 보세요.

## 풀이

<details><summary>풀이 보기</summary>

먼저 손으로 해 볼게요. 내적은 3 곱하기 0 더하기 4 곱하기 5, 20이에요. a와 e는 길이가 둘 다 5라서, 코사인은 20 나누기 25, 0.8이에요.
거리는 같은 자리끼리 빼면 3과 마이너스 1. 제곱해서 9와 1, 더하면 10, 10의 제곱근은 3.16이에요.
이제 코드로 확인해요. 파일 끝에 e를 만들고, 코사인과 거리를 찍어요.
코사인 0.8, 거리 3.16. 손으로 계산한 값과 똑같아요. 이렇게 손 계산과 코드를 맞춰 보면 공식이 금방 손에 익어요.

영상에서 입력한 그대로입니다.

- `a2/similarity.py`를 엽니다.
- 파일 맨 끝으로 갑니다.

```python

e = np.array([0, 5])
print("과제 a와 e: 코사인", round(cosine(a, e), 2), "  거리", round(np.linalg.norm(a - e), 2))
```

- 실행: `uv run python a2/similarity.py`
