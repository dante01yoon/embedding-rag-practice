# 34. Adaptive RAG: 질문의 종류를 보고 길 고르기

> B7~B9 · 답의 품질과 고급 RAG · 수업 34 / 60 · [전체 목록](../../README.md#수업-목록)

## 이 수업에서 하는 것

- Adaptive RAG는 분류기로 갈 길을 골라요. 잡담은 바로, 관계없는 질문은 정해진 문장, 문서 질문만 그래프로 보내요.
- 분류기가 내놓는 모든 답에 길을 만들고, 길 고르기의 비용까지 세서, 입력 비율로 이득을 판단해요.
- 왜 이렇게 하냐면, 잡담에 쓰는 무거운 검색은 낭비지만 길 고르기도 공짜가 아니고, 분류기도 틀리기 때문이에요. 그래서 비율로 이득을 재고, 잘못 막는 쪽을 더 조심해요.

## 과제

잡담이 훨씬 많은 서비스라면 어떨까요? 잡담을 다섯 배로 늘려서 호출 수를 다시 비교해 보세요.

## 풀이

<details><summary>풀이 보기</summary>

inputs 줄에서 EVERYDAY에 곱하기 5를 붙여요.
입력 79개에, 늘 그래프로 보내면 615번, 길을 고르면 314번이에요.
거의 절반으로 줄었어요. 잡담이 많을수록 길 고르기의 이득이 커져요. 같은 코드라도 어떤 입력이 들어오는지에 따라 판단이 바뀌어요. 그래서 실제 로그의 비율로 재요.

영상에서 입력한 그대로입니다.

- `b8/adaptive.py`를 엽니다.
- 64행으로 갑니다.
- 그 자리의 줄 1개를 지웁니다.

```python
inputs = EVERYDAY * 5 + [x["question"] for x in json.load(open("k8s/qa_ko_short.json"))]  # 잡담 40 + 문서 질문 39
```

- 실행: `uv run python b8/adaptive.py`

</details>
