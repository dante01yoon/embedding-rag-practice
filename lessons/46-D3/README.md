## 이 수업에서 하는 것

- 청크 이름을 문서 경로와 내용 해시로 만들면, 바뀐 청크만 골라 임베딩할 수 있어요. 오늘은 2개였어요.
- 그리고 오늘 문서에 없는 청크를 꼭 지워야 해요. 빠뜨리면 11개의 유령 청크가 지운 문서로 답했어요.
- 왜 이렇게 하는지도 다시 볼게요. 전체를 다시 하면 73초, 바뀐 것만 하면 1초도 안 걸려요. 그 차이를 만드는 게 내용 해시로 만든 이름이에요.

## 과제

청크 이름을 내용 해시가 아니라 몇 번째 문서의 몇 번째 청크라는 위치 번호로 붙였다면, 오늘 몇 개를 다시 임베딩해야 했을까요?

## 풀이

<details><summary>풀이 보기</summary>

어제와 오늘 문서를 위치 번호로 이름 붙이고, 같은 이름인데 내용이 달라진 청크를 세요.
3,008개예요. 해시 이름으로는 2개였는데요. 앞쪽 문서 하나를 지우니 뒤의 문서들 번호가 모두 한 칸씩 밀려서, 내용은 같은데 이름이 바뀌었어요.
그래서 이름은 위치가 아니라 내용에서 만들어야 해요. 그래야 지우고 넣는 것이 정확히 바뀐 만큼만 일어나요.

영상에서 입력한 그대로입니다.

- `d3/reindex.py`를 엽니다.
- 파일 맨 끝으로 갑니다.
- 51행으로 갑니다.

```python
by_pos = lambda docs: {f"{i}-{j}": c for i, d in enumerate(docs) for j, c in enumerate(split(d["text"], 500, 100))}  # 이름 = 몇 번째 문서의 몇 번째 청크
a, b = by_pos(old), by_pos(new)
print(f"위치 번호로 이름을 붙였다면 → 다시 임베딩 {sum(a.get(k) != c for k, c in b.items()):,}개")
```

- 실행: `uv run python d3/reindex.py`
