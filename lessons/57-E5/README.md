## 과제

그럼 질문이 조회형인지 집계형인지는 누가 정할까요? LLM에게 질문 유형을 나누게 해서, 질문마다 알맞은 경로로 보내 보세요.

## 풀이

<details><summary>풀이 보기</summary>

질문 여덟 개를 준비했어요. 넷은 전부 모아야 하는 질문, 넷은 하나를 찾는 질문이에요. route는 LLM에게 조회인지 집계인지 한 단어로 답하게 해요.
여덟 개 모두 맞게 나눴어요. 퓰리처상 질문은 11권을 모아 9권, 히가시노 게이고 질문은 17권을 모아 16권을 골랐어요.
현업에서는 이렇게 질문 유형을 먼저 나누는 단계를 라우팅이라고 불러요. 질문마다 맞는 길이 따로 있다는 게 오늘의 핵심이에요.

영상에서 입력한 그대로입니다.

- `e5/agg.py`를 엽니다.
- 71행으로 갑니다.

```python

QS = [("퓰리처상을 받은 책을 전부 알려줘", "집계"), ("히가시노 게이고의 책은 몇 권이야?", "집계"), ("네뷸러상 받은 소설 목록", "집계"), ("도스토옙스키 작품을 다 보여줘", "집계"),
      ("삼체는 어떤 이야기야?", "조회"), ("노인과 바다의 작가는 누구야?", "조회"), ("화씨 451의 제목은 무슨 뜻이야?", "조회"), ("빼앗긴 자들의 무대는 어디야?", "조회")]

def route(q):  # 질문 유형 나누기: 하나를 찾는 질문 → 조회형, 해당하는 것을 전부 모으는 질문 → 집계형
    return "집계" if "집계" in ask(f"질문이 자료 한두 개로 답하는 '조회'인지, 해당하는 것을 전부 모아야 하는 '집계'인지 한 단어로 답하세요.\n질문: {q}") else "조회"

hit = sum(route(q) == want for q, want in QS)
print(f"질문 유형 나누기 | 맞힘 {hit}/{len(QS)}")
for q, _ in QS[:2]:
    kw, docs = scan(q)
    print(f"  {q} → 집계형 · 검색어 '{kw}' · 책 {len(docs)}권 · 해당 {len(set().union(*[extract(q, docs[i:i + 8]) for i in range(0, len(docs), 8)]))}권")
json.dump(cache, open(CACHE, "w"), ensure_ascii=False)
```
