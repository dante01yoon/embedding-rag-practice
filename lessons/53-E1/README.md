## 과제

후보를 150개 대신 50개만 넘기면, 실패율과 시간은 어떻게 될까요?

## 풀이

<details><summary>풀이 보기</summary>

N을 50으로 바꿔서 다시 돌려요.
후보 50개로는 실패율이 0.0퍼센트, 시간은 질문당 2.14초예요.
실패율은 똑같이 0퍼센트인데, 시간은 17.21초에서 2.14초로 8분의 1이에요. 우리 데이터에서는 50개면 충분했어요. 후보 수에는 정해진 답이 없어서, 이렇게 줄여 가며 재 보고 실패율이 나빠지기 직전을 찾아요.

영상에서 입력한 그대로입니다.

- `e1/ctx.py`를 엽니다.
- 41행으로 갑니다.
- 그 자리의 줄 1개를 지웁니다.

```python
N = 50  # 재순위에 넘길 후보 수
```

- 실행: `uv run python e1/ctx.py`

</details>
