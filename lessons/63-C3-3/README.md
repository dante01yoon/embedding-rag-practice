# 63. 탐정의 도구를 다시 만든다

> C3 · 문서가 수십만 개일 때 — 끌어와서 grep · 수업 63 / 66 · [전체 목록](../../README.md#수업-목록)

## 이 수업에서 하는 것

- 파일 경로 대신 문서 번호만 주고받아 폴더 밖 접근을 막고, find 결과에 이름(r1, r2)을 붙여 그 안에서 조건을 겹쳐 찾게 했어요.
- 줄 수 대신 글자 수와 offset으로 긴 문단도 끊어 읽고, 모든 도구가 첫 줄에 상태를 적어 모델이 거절을 보고 고치게 했어요.
- 턴 한도나 토큰 한도에 걸린 실행은 오답과 따로 분류해 기록해요.

## 실행

먼저 문서 묶음을 받고 (이미 받았다면 건너뜁니다): [C3 자료 받기](../../c3/README.md)

`find`는 `rg`(ripgrep)를 부릅니다. 설치돼 있는지 확인합니다.

```bash
rg --version
```

수업 명령 ① 완성된 도구로 1만 개 묶음 뒤지기. 파이썬 창(`>>>`)이 열리면 한 줄씩 입력합니다.

```bash
uv run python -i c3/try_tools.py
```

```python
find("닛폰햄")
find("1975년", within="r1")
find("월간 MVP", within="r2")
read("w199008", at="월간 타율")
exit()
```

수업 명령 ② 도구가 돌려주는 상태 보기. `try_tools.py`를 다시 열고 입력합니다.

```python
find("서울")
find("서울", offset=20)
find("없는낱말zzz")
read("../../.env")
find("폐교", within="w461996")
exit()
```

- 차례로 `truncated`(716개 중 1~20번째), `truncated`(21~40번째), `none`, `bad_request`, `bad_request`가 나옵니다.
- `read("../../.env")`는 문서 번호가 아니라서 거절됩니다. 파일은 열지 않습니다.
- 화면을 비우려면 `clear()`를 입력합니다.

수업 명령 ③ 에이전트가 1만 개 묶음에서 질문 하나를 푼 강사의 기록 보기.

```bash
uv run python c3/show.py h04
```

저장소 맨 위 폴더에서 실행합니다. 세 명령 모두 모델을 부르지 않으니 **OpenRouter 키가 필요 없고** 비용도 들지 않습니다.

## 과제

조건이 두 개인 질문을 하나 골라 `find` 두 번으로 좁혀 보세요. 예를 들어 「아카데미 각색상」과 「1983년」이라는 두 조건을 써 볼 수 있어요. 첫 호출의 결과 이름을 둘째 호출의 `within`에 넣는 식으로 적어 보세요.

## 풀이

<details><summary>풀이 보기</summary>

예시 조건으로 1만 개 묶음에서 실행한 풀이예요.

- 먼저 `find`에 아카데미 각색상을 넣으면 결과 r1으로 콜 미 바이 유어 네임, 피에르 불, 아론 소킨 문서 3개가 나와요.
- 이어서 `within`에 r1을 주고 1983년을 한 번 더 찾으면, 새 결과 r2에는 콜 미 바이 유어 네임 문서 딱 1개만 남아요. 발췌에도 「1983년 북부 이탈리아를 배경으로」라는 문장이 바로 보여요.
- 후보가 3개에서 1개로 줄었으니, 이제 그 문서 하나만 `read`로 열면 돼요.
- 반대로 1983년부터 찾으면 첫 결과가 226개예요.

영상에서 입력한 그대로입니다.

- 실행: `uv run python -i c3/try_tools.py`

```python
find("아카데미 각색상")
find("1983년", within="r1")
find("1983년")
```
