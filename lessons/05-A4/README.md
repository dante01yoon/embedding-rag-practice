# 05. TF-IDF에서 BM25까지

> PART A · 기초 개념 · 수업 5 / 60 · [전체 목록](../../README.md#수업-목록)

## 이 수업에서 하는 것

- BM25는 나온 횟수, 드문 정도, 문서 길이로 점수를 매겨요.
- 한국어는 조사 때문에 띄어쓰기로 자르면 놓쳐요. 형태소로 잘라야 해요.
- 실제 위키 문서에서는 자르는 방법만 바꿔도 0.41이 0.65가 됐어요. 오류 없이 돌아도 조용히 틀릴 수 있으니, 자른 조각을 꼭 눈으로 확인해요.

## 과제

두 가지예요. wiki.py에 k1 값을 0.5와 3으로 줘서 다시 재 보고, 문서 파일에 '반려견 밥 추천'을 넣어 강아지 사료로 검색해 보세요. 두 방법 모두 못 찾는 이유도 생각해 보세요.

## 풀이

<details><summary>풀이 보기</summary>

k1을 0.5로 주고 다시 재요.
형태소는 0.68로 올랐어요. 이번엔 3으로 줘요.
0.61로 내려가요. 위키 문단은 질문 단어가 한두 번만 나와도 충분해서, 횟수 점수가 빨리 멈출수록 좋았어요. 다만 같은 질문 100개로 고른 값이라, 실제로 바꿀 땐 따로 떼어 둔 질문으로 다시 확인해요.
다음은 문서 파일 끝에 반려견 밥 추천을 넣고 실행해요.
두 방법 모두 반려견 밥 추천이 0점이에요. 질문은 강아지 사료, 문서는 반려견 밥. 겹치는 글자가 하나도 없으니까요.
문서 하나만 더했는데 맨 위 점수가 0.60에서 0.70으로 바뀐 것도 보이죠. 전체 문서 수가 늘어서 드문 정도가 다시 계산됐거든요. 그래서 BM25 점수는 색인이 다르면 서로 비교하지 않아요.

영상에서 입력한 그대로입니다.

- `a4/docs_ko.txt`를 엽니다.
- 실행: `uv run python a4/wiki.py 0.5`
- 실행: `uv run python a4/wiki.py 3`
- 파일 맨 끝으로 갑니다.

```
반려견 밥 추천
```

- 실행: `uv run python a4/bm25.py`
