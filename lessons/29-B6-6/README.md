# 29. 청킹 방법 다섯 가지 · 공정하게 비교하기

> B6 · 검색 개선 · 수업 29 / 60 · [전체 목록](../../README.md#수업-목록)

## 이 수업에서 하는 것

- 청킹 방법 다섯 가지를 같은 2,000자 예산으로 비교했어요. 고정 길이, 문단, 재귀, 시맨틱, 계층이에요.
- 평가셋이 문단 청크에서 나왔을 땐 문단이 이겼고, 원문 문장에서 새로 뽑으니 재귀가 이겼어요. 시험지가 공정한지부터 확인해요.
- 이유를 다시 볼게요. 청크 하나가 벡터 하나라서, 이야기의 경계를 지킬수록 벡터가 또렷해지고 답할 재료가 한 청크에 모여요. 그래서 경계를 지키는 재귀와 계층이 앞섰어요. 그리고 비교는 같은 글자 수, 같은 출발선의 시험지로 해야 공정해요.

## 과제

재귀 청킹의 청크 크기를 500자에서 300자로 줄이면 어떻게 될까요?

## 풀이

<details><summary>풀이 보기</summary>

chunk_size를 300, 오버랩을 60으로 바꿔요.
재귀의 청크는 3,427개에서 5,707개로 늘었는데, 정답 문장 포함률은 76.2퍼센트로 똑같아요.
같은 2,000자 안에 작은 청크를 더 많이 담을 뿐이라, 이 문서에서는 크기보다 경계를 지키는 게 더 중요했어요. 대신 청크가 많아지면 임베딩하고 저장할 양이 늘어요.

영상에서 입력한 그대로입니다.

- `b3x/compare.py`를 엽니다.
- 32행으로 갑니다.
- 그 자리의 줄 1개를 지웁니다.

```python
rec = RecursiveCharacterTextSplitter(chunk_size=300, chunk_overlap=60, separators=["\n## ", "\n### ", "\n\n", "\n", ". ", "다. ", " ", ""])
```

- 실행: `uv run python b3x/compare.py`

</details>
