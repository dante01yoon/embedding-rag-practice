## 이 수업에서 하는 것

- 단어 검색에 임베딩을 더하면 결과가 없는 검색이 사라지고, 오타와 묘사형 같은 롱테일 질의를 잡아요.
- 다만 점수 눈금이 달라서 그냥 더하면 망가져요. 분위수 보정으로 같은 눈금에 놓고 섞어요.
- 왜 이렇게 할까요? 기존 시스템을 그대로 두면 위험이 작고 빨리 내보낼 수 있어요. 점수 모양만 맞추면 뒤쪽은 바뀐 걸 몰라도 되니까요.

## 과제

묘사형이 아직 벡터보다 낮아요. 가중치 w를 0.5에서 0.3으로, 단어 쪽을 줄여 보면 어떻게 될까요?
