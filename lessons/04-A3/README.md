# 04. 임베딩은 어떻게 학습되나

> PART A · 기초 개념 · 수업 4 / 60 · [전체 목록](../../README.md#수업-목록)

## 이 수업에서 하는 것

- 임베딩은 문장을 숫자 목록, 그러니까 지도 위 점으로 바꿔요.
- 모델은 옆 단어, 문맥, 그리고 짝 맞추기로 뜻을 배워요. 그래서 글자가 달라도 뜻이 같으면 가까워져요.
- 그리고 약한 곳도 봤어요. 같은 글자에 끌리고, 반대말과 숫자는 잘 가려내지 못해요.

## 실행

```bash
uv run python a3/heatmap.py
uv run python a3/probe.py
```

저장소 맨 위 폴더에서 실행합니다. 처음이라면 [벡터 파일 만들기](../../README.md#벡터-파일-만들기)를 먼저 확인하세요.

## 과제

문장 파일에 내 문장 두 개를 추가해서, 어느 무리에 붙는지 히트맵으로 확인해 보세요.

## 풀이

<details><summary>풀이 보기</summary>

문장 파일 끝에 햄스터 먹이 질문과 적금 이자 질문을 더하고 다시 실행해요.
햄스터 질문은 고양이 간식과 0.61로 가장 가깝고, 금리 쪽과는 0.33에서 0.35예요. 적금 질문은 예금 상품과 0.68로 가장 가까워요. 둘 다 제 무리를 찾아갔어요.

영상에서 입력한 그대로입니다.

- `a3/sentences_ko.txt`를 엽니다.
- 파일 맨 끝으로 갑니다.

```
햄스터 먹이는 어디서 사요?
적금 이자는 어떻게 계산해요?
```

- 실행: `uv run python a3/heatmap.py`
- `a3/heatmap_ko.png`를 엽니다.

</details>
