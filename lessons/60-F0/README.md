# 60. 통합 프로젝트 미리보기 — 시스템 설계 (업데이트 예정)

> F · 통합 프로젝트 (업데이트 예정) · 수업 60 / 60 · [전체 목록](../../README.md#수업-목록)

## 이 수업에서 하는 것

- 지금까지 수업마다 조각을 하나씩 만들었어요. 문서를 모으는 수집, 하이브리드 검색과 리랭킹, 골든셋 평가, 캐시, 권한 필터, 트레이스, 그리고 채팅 화면이에요.
- 그런데 이 조각들은 아직 따로따로 돌아요. 수업마다 파일이 있을 뿐, 한 시스템으로 이어진 적은 없어요.
- 그래서 이번 파트에서는 이 조각들을 하나로 묶어요. 쿠버네티스 한국어 문서를 근거로 답하는 사내 문서 도우미를 만들어요.
- 먼저 전체 그림이에요. 사용자는 브라우저에서 ui, Streamlit 채팅 화면에 질문을 써요. ui는 그 질문을 api, FastAPI 서버로 보내요.
- api 뒤에는 저장소가 두 개 있어요. cache는 Redis예요. 같은 질문이면 여기서 바로 답을 꺼내요. db는 Postgres에 pgvector를 붙인 거예요. 청크와 벡터, 색인 버전, 권한 정보가 여기 들어 있어요.
- 답을 쓰는 LLM은 바깥에 있어요. 강의 내내 쓴 OpenRouter로 불러요. 그리고 api는 요청마다 트레이스를 한 줄씩 남겨요.
- worker는 뒤에서 따로 도는 일꾼 프로그램이에요. 쿠버네티스 문서 원본을 보다가, 바뀐 문서만 다시 청킹하고 임베딩해서 db에 넣어요.
- ui, api, worker, db, cache, 이 다섯 서비스가 docker compose 하나로 함께 떠요. 그리고 GitHub Actions의 평가 게이트가, 골든셋 점수가 떨어지면 배포를 막아요.
