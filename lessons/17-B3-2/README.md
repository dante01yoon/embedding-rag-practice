# 17. 문서 불러오기: 웹 문서와 PDF

> B3 · RAG 기초 · 수업 17 / 60 · [전체 목록](../../README.md#수업-목록)

## 이 수업에서 하는 것

- 웹 문서는 프런트 매터를 떼고, 용어 태그는 글자를 살린 다음, 나머지 태그를 지웠어요. 순서를 바꾸면 단어가 조용히 사라져요.
- PDF는 펼친 쪽을 나눠 읽고 머리말을 버렸어요. 표는 글자로 뽑으면 칸이 무너지니, 원본과 비교하고 한 행을 한 문장으로 바꿔 넣어요.
- 이유도 기억해요. 웹 문서는 원본을 읽어야 메뉴가 안 섞이고, PDF는 인쇄용이라 글자와 좌표만 있어요. 읽는 순서, 반복되는 제목, 표의 칸은 우리가 직접 챙겨야 해요.

## 과제

pdf.py의 PAGE를 0, 표지로 바꿔서 읽어 보세요. 고쳐 읽기에도 이상한 점이 보일 거예요. 원인을 찾아 고쳐 보세요.

## 풀이

<details><summary>풀이 보기</summary>

PAGE를 0으로 바꾸고 실행해요.
고쳐 읽기에 이이용용 지지침침, 해해설설서서. 글자가 두 번씩 나와요. 표지의 굵은 제목을 같은 자리에 두 번 겹쳐 찍어서 진하게 만든 거예요. 눈에는 한 글자지만, 파일 안에는 두 글자예요.
그래서 page에 dedupe_chars를 붙여요. 같은 자리에 겹친 같은 글자를 하나로 합쳐 주는 기능이에요.
이제 이용 지침, 해설서로 제대로 나와요. 이렇게 PDF는 장마다 다른 방식으로 망가질 수 있어요. 읽은 글은 꼭 몇 장씩 열어 보세요.

영상에서 입력한 그대로입니다.

- `b3/pdf.py`를 엽니다.
- 4행으로 갑니다.
- 그 자리의 줄 1개를 지웁니다.

```python
PAGE = 0  # 표지
```

- 실행: `uv run python b3/pdf.py`
- 13행으로 갑니다.
- 그 자리의 줄 1개를 지웁니다.

```python
    page = pdf.pages[PAGE].dedupe_chars()  # 겹쳐 찍은 글자 하나로
```

- 실행: `uv run python b3/pdf.py`
