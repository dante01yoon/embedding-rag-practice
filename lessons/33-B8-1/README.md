# 33. LangGraph로 스스로 고치는 RAG (CRAG)

> B7~B9 · 답의 품질과 고급 RAG · 수업 33 / 60 · [전체 목록](../../README.md#수업-목록)

## 이 수업에서 하는 것

- LangGraph로 검색, 채점, 다시 쓰기, 답하기를 노드로 잇고, 갈림길과 되돌아가는 길을 만들었어요.
- 되돌아가는 길에는 멈추는 조건이 꼭 필요해요. 그리고 똑똑해 보이는 루프도 안의 채점이 맞아야 도움이 돼요. 그냥 검색과 같은 자로 재요.
- 이유도 같이 기억해 두세요. 노드는 상태 메모로만 이어져서 서로 몰라도 되고, 조건부 엣지 덕분에 되돌아가는 길을 그대로 그릴 수 있어요. 대신 단계마다 LLM을 부르니, 같은 성적표로 재서 이득이 있을 때만 써요.
