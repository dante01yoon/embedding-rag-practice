# 24. 하이브리드 검색: 키워드와 벡터 섞기

> B6 · 검색 개선 · 수업 24 / 60 · [전체 목록](../../README.md#수업-목록)

## 이 수업에서 하는 것

- BM25와 코사인은 점수 단위가 달라서 그냥 더하면 한쪽이 이겨요. RRF는 순위로 합쳐서 단위가 다른 검색도 공평하게 섞어요.
- 그리고 평균만 보지 말고 질문별로 열어 봐요. 하이브리드는 메워 주기도 하고, 묻어 버리기도 해요.
- 이유를 다시 볼게요. 점수는 질문마다 크기가 달라서 그냥 더하면 한쪽이 정하고, 정규화는 가중치를 따로 정해야 해요. RRF는 순위만 봐서 정할 게 k 하나뿐이고, 두 목록에서 모두 위에 있는 걸 올려요. 대신 한쪽에만 있는 정답은 묻힐 수 있어요.

## 과제

rrf에 띄어쓰기 BM25까지 세 목록을 넣고, k를 60에서 10으로 바꿔 보세요. 성적표가 어떻게 바뀌는지 보세요.

## 풀이

<details><summary>풀이 보기</summary>

search가 돌려주는 사전에, 세 목록을 k 10으로 합친 줄을 하나 더해요.
셋 다 k 10의 Recall@4는 0.97, MRR은 0.94예요. 오늘 성적표에서 가장 좋아요. 약했던 띄어쓰기 BM25도 한 목소리를 보태니 도움이 됐어요.
그렇다고 이게 정답은 아니에요. 질문 39개에서 한 문제 차이예요. 섞는 방법도 골든셋으로 재 보고, 질문을 늘려 다시 확인한 뒤에 정해요.

영상에서 입력한 그대로입니다.

- `b6/hybrid.py`를 엽니다.
- 43행으로 갑니다.
- 그 자리의 줄 1개를 지웁니다.

```python
    return {"BM25 띄어쓰기": a, "BM25 형태소": b, "bge-m3": v, "하이브리드(형태소+벡터)": rrf(b, v), "셋 다 k=10": rrf(a, b, v, k=10)}
```

- 실행: `uv run python b6/hybrid.py`

</details>
